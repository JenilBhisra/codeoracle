# Demo Script: CodeOracle

This script outlines the flow of the hackathon pitch and demonstration.

---

## 1. Intro & Hook (30 seconds)
* **Visual**: Slide/Landing Page displaying: *"CodeOracle: Understand, test, and modernize legacy code."*
* **Narrative**: 
  > "Every developer has experienced the dread of inheritance—inheriting a massive, undocumented, 10-year-old codebase. You're told to refactor it, but you don't know what will break. Today, we're introducing CodeOracle."

---

## 2. Problem & Solution (45 seconds)
* **Visual**: High-level problem slides showing the pain points (no tests, dead code, manual analysis).
* **Narrative**:
  > "CodeOracle automatically reads your project structure, maps its internal relationships, and generates unit tests for you—turning hours of legacy code navigation into seconds."

---

## 3. Live Walkthrough (2 minutes)
* **Visual**:
  1. **Upload Phase**: Drag and drop a legacy zip file or specify a local directory path.
  2. **Analysis Interface**: Show the generated directory structure and visual dependency nodes.
  3. **Modernization & Test Drafts**: Select a legacy function, click "Generate Tests", and inspect the generated test suite block.
* **Narrative**:
  > "Watch as we upload a legacy directory. The backend parses it, builds an internal representation, and maps all imports. Now, with a single click, we generate robust unit tests for our main logic..."

---

## 4. Summary & Q&A (45 seconds)
* **Visual**: Architecture summary, next-step roadmap, and "Thank You" slide.
* **Narrative**:
  > "CodeOracle bridges the gap between legacy pain and modern velocity. Thank you, and we're open for questions!"
